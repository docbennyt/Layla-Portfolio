## 📖 About the Project

This is not a generic template. This portfolio was precision-crafted to feel like a premium, custom digital storybook. The aesthetic leans into a soft academic and watercolor elegance—complete with floral corners, layered paper textures, and polaroid framings.

It is designed to serve as a flagship student portfolio for:
- Scholarship visibility
- School ambassador profiles
- Leadership recognition
- Personal branding

## ✨ Key Features

- **Premium Aesthetic:** Warm paper backgrounds, gold and watercolor blue accents, and curated typographic hierarchy.
- **Scrapbook Journey:** A beautifully filtered grid of "milestones", "leadership moments", and "personal style" framed like polaroids and tape-mounted photos.
- **Engaging Motion:** Subtle hover states, floating decorative elements, and a delicate watercolor mouse-trail for a whimsical, memorable touch.
- **Fully Responsive:** Looks and feels rich and equitable from the smallest mobile device to large desktop monitors.
- **Semantic & Accessible:** Engineered with clean HTML5 structures and equitable ARIA patterns.

## 🛠️ Tech Stack

This project deliberately avoids heavy frameworks to keep the payload remarkably light and the deployment straightforward:
- **HTML5** (Semantic structure)
- **Vanilla CSS3** (Custom design system, fluid typography, no frameworks)
- **Vanilla JavaScript** (Typewriter effect, custom canvas-free SVG interactions, intersection observers)

## 🎨 Design Language

### Color Tokens
- **Base:** Soft cream / warm paper (`#FAF8F5`)
- **Primary Text:** Deep navy for credibility and contrast (`#1A2B4C`)
- **Accents:** Sunflower Gold (`#D4AF37`) & Watercolor Blue (`#9DBAD5`)

### Typography
- **Headings (Accent):** `Dancing Script` – used sparingly for decorative subheads.
- **Body & UI:** `Poppins` – geometric, versatile, and highly readable.

## 🚀 How to Run Locally

Since this is a static site without build steps:

   ```bash

   ```
2. Open the directory.
3. Simply launch `index.html` in your browser.
   *(Alternatively, run it via VSCode Live Server or any basic HTTP server)*
